# ESE 5190 Embedded Robotics Platform

A three-person embedded robotics project focused on sensing, real-time control, communication, and hardware-software integration.

> Developed as the final project for ESE 5190: Smart Devices at the University of Pennsylvania.

## Project Status

🚧 In development — Fall 2026

The system architecture and project scope are currently being finalized.

## Objectives

The project aims to integrate:

- Embedded sensing
- Real-time control
- Actuation
- Device communication
- Hardware-software integration

Additional components such as ROS 2 may be incorporated depending on the final system architecture.
